NOTA TÉCNICA — LAZY-LOAD DE FUNDOS
----------------------------------
O Elementor esconde as imagens de fundo dos containers até o JavaScript
adicionar a classe "e-lazyloaded":

  .e-con.e-parent:nth-of-type(n+2):not(.e-lazyloaded) * {
      background-image: none !important; }

Como o JavaScript do Elementor está quebrado neste pacote (tenta carregar
trechos do backend WordPress que não existe mais), essas imagens só
aparecem em parte dos navegadores e situações. Ao inspecionar a página,
force a classe antes de concluir que um fundo não existe:

  document.querySelectorAll('.e-con').forEach(e=>e.classList.add('e-lazyloaded'))
